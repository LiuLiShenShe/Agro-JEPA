## 7. How to read this

1. **Global permutation (A1)** quantifies how much the model uses the time channel at all. It destroys both the span class and the exact interval.
2. **Within-pair_type permutation (A2)** keeps every sample in its own span family and only breaks the sample → exact-interval link. The residual increase is therefore the part that depends on the precise interval.
3. **Pair_type train mean (A3)** removes all within-class variation while keeping a correct short/long level. It is the strongest coarse-conditioning control.
4. **Pair_type × harvest_year permutation (A4)** additionally holds the year composition fixed, so the A2 result is not explained by year-specific interval distributions.
5. If A2/A3/A4 are all close to each other, the model is not resolving the exact interval beyond the span level; the evidence would then support coarse growth-stage conditioning, not per-sample interval precision.

## 8. Bounded answer from these numbers

- Global loss of interval information (A1): **+11.46%** [+11.23%, +11.69%].
- Part that survives keeping the span class (A2): **+6.91%**.
- Part attributable to the exact interval beyond the class mean (A2 minus A3): **+1.30%** of MSE; the remaining +5.61% is the coarse level of the interval.
- Year-stratified permutation (A4) gives **+6.65%**, -0.25 percentage points relative to A2, so the within-span result is not a year-composition artefact.

A2 vs A3, with their bootstrap intervals (+6.71%–+7.13% vs +5.40%–+5.84%): the A2 interval lies entirely above the A3 interval, so the model does carry a small amount of sample-level interval information. The coarse level still accounts for 49% of the global permutation effect, so fine interval resolution is a minor part of how this checkpoint uses time.
